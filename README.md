# Coding 1: In-class assignment 5 — graphics

You have ten minutes. Read six lines of Python and answer two questions.

## Task

Open `assignment.py`. Write short Python comments beginning with `#` below each
`# Your answer:` prompt. Answer in your own words. **Do not change the code.**

Predict the plot before running the script. An `Axes` object means a plotting
panel, not an individual x-axis or y-axis. No data files are needed.

## Run it (optional)

To check your prediction, run these commands from this repository's folder:

```bash
uv sync --locked
uv run python assignment.py
```

Close the plot window when you are done. You can complete both questions by
reading the code even if your computer cannot display the plot.

1. Fork this repository to your own GitHub account.
2. Clone **your fork** and open its folder in VS Code.


5. Check that your answers are visible in your fork on GitHub before leaving

Each numbered question is worth one point. Include a brief explanation for
Question 1 and answer both parts of Question 2. Short comments are enough.

- **2**: both questions answered correctly.
- **1**: one question answered correctly.
- **0**: neither question answered correctly, or no substantive answers.
